Provision a device adb

1
Start from a clean device
Factory-reset (or fresh) device with no accounts added — Device Owner can only be set before an account exists.
2
Install the AIO MDM agent
Side-load the agent APK over adb.
adb install -r skorra-agent.apk
3
Set it as Device Owner
This grants full device management (kiosk, app install, reboot, wipe, config).
adb shell dpm set-device-owner \ {{.AdminComponent}}
4
Point it at this server
Open the agent app, enter the server URL + device key below (or bake them into the build), and tap Save & connect. The device appears in Fleet within seconds.
Prefer QR / zero-touch? Create an enrollment profile above and scan its QR from a factory-reset device's welcome screen (tap 6×) — no adb needed.
