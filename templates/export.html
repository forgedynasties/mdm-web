Row timestamps

Fixed cycle marks

Check-ins exports rows at the devices' actual check-in times. Cycles exports one row per device at fixed marks — start, start + interval, … — each carrying the last value the device reported, held forward until it reports something different. Devices only transmit when a value actually changes, so a held value is what the device was reading, not a guess. Cells go blank only once a device has been silent long enough to count as genuinely offline.

Sampling interval

1 row / 30 sec

Reduce data volume by picking one row per interval per device. "All" exports every checkin. Buckets start at your chosen start time. Every row carries timestamp in your local time, timestamp_utc, and sample_at: the moment the check-in behind the values was recorded, which is the point you will find on the device graph.
