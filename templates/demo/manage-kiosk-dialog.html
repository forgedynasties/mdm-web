Kiosk config dialog: match the device-page bar

The Manage bulk-apply dialog right now is a plain form: a Lock/Unlock toggle above a target `<select>` stack, nothing like the device page's kiosk modal (searchable app grid, dynamic footer buttons, one clear job per screen). Two ways to bring it up to that bar while still fitting a target picker in, which the device page's version never needed.

Minimal change, same modal shape as device.html. "Applies to" becomes one more form-row — a segmented All/Restaurant/Group/Device control, same visual weight as "Locked app" below it — instead of a separate section with plain HTML selects. Footer buttons are dynamic exactly like the device page's ("Enable kiosk on 17 devices", not a generic "Apply").
One job per screen. Step 1 picks the target with bigger, friendlier scope cards (more room to browse restaurants/groups than a cramped inline row); Step 2 is the device.html app picker, untouched. A step tracker up top and a back arrow instead of cramming both jobs onto one screen.
