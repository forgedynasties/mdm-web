Fleet rows — alignment options

Same ten devices in each: the T7s and Kiosk 22s from stage, the Pixel 6 and an HK1 dongle on MDM-lite. Every option puts every row on one shared column grid, so serials, temperatures and RAM sit at the same x on every row whatever the name length, tags or power source.

Surprise ✦

One header, one line per device. Labels live in the header, so cells hold only values. Serial always starts the second line of the device cell; "New" trails it instead of pushing it. Power is a fixed icon slot plus text. Rows without a battery show "—" under Cycles so no column goes ragged.

Grouped by device type. A mixed fleet has different vitals per type: T7s have a battery and cycles, kiosks and dongles are on mains. Grouping lets each section show only the columns its devices have, with a one-line summary in the group header.

Table with meters. Battery and RAM as bars with the number beside them, so a full or drained device stands out without reading digits. Mains devices show a flat grey bar.
