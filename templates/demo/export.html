Reworking Export Data

Two takes on the CSV export screen. Both add the thing it's missing most: an honest sense of what you're about to download before you click.

Today it's: four stacked form cards — Time Range, Row Timestamps, Sampling Interval, Columns — that you fill in blind, then hope the file is right. No preview, no row count, no size estimate.
Shared idea: a live row + file-size estimate that moves as you configure — so a stray "30 days, every check-in, all columns" reads as ≈ 2.1M rows · 240 MB before you commit, not after.
