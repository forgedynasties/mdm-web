Wireless adb and "device not found"

Two dashboard changes to decide. Wireless adb: the server and client 1.4.9 already take an adb_tcp command (admin only, one device at a time, off by itself after a set time); this is where the control lives on the device page. Device not found: today an unknown serial gets a bare 404 in plain text.

1 · Wireless adb on the device page

A · Item in the device's ⋯ menu, opening a small dialog

Out of the way, next to Reboot and Shell. Good: no new chrome for a rare, admin-only action. Bad: when adb is on there is nothing on the page saying so — you only find out by opening the menu.

B · A row in the Security card, next to the status it changes Recommended

The Security card already lists adb and developer options; the switch sits on the adb row, with the address and the time left when it is on. Good: the state and the control are in one place, and "adb is open on this device" is visible to anyone reading the card. Bad: one more row in a card most people skim.
