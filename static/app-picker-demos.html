App picker: queue several variants of one app

In Actions → Install app → Pick apps from the library, an app with variants (Nugget has prod, internal, uatv2, qa and staging) only lets you pick one variant: the picker remembers one choice per app. The dropdown under the tile changes the version, not the variant. Mocks use the real tokens and sizes, so light and dark are accurate. Pick one.

CurrentA · Variant chipsB · Variant panelC · Flat list
What is wrong today. (1) One choice per app: the selection is stored by app family, so choosing "internal" replaces "prod"; you cannot queue both. (2) The version dropdown sits outside the tile's border, so it looks detached and is cut off at the card edge. (3) The "5 variants · 7 versions" pill and "INSTALLED" crowd each other in a narrow tile. (4) Nothing says which variant the dropdown belongs to.

Recommendation

B · the variant panel. It fixes both complaints: you can tick any number of variants, and every version dropdown sits on its own labelled row inside a bordered panel, so nothing hangs off the edge. A keeps today's look but squeezes three dropdowns into one card. C is better if you usually pick many variants of many apps. In every option a single-variant app behaves as now (one click selects it). Queueing "prod + internal + qa" then adds one install per chosen variant to the same devices, each named by its variant so the queue stays readable.
