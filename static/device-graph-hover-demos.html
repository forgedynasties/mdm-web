The column of big numbers on the left goes, so each chart gets the full width, and the values appear only where the pointer is. Four ways to show them. Every mock shows the pointer at 11:25 (the dashed line). Each chart keeps its name as a small label in its corner.

V1 · One tooltip beside the pointer my pick

A single card follows the pointer and lists all three values at that moment, the battery note (phone on pad, charging) and any command or build marker under the pointer. The dots on each line show where the values were read.

V2 · A value bubble on each chart

Each chart puts its own value in a small bubble next to the dot, in the line’s colour. The time sits on the axis under the line.

V3 · The value in each chart’s label

The chart names in the corner ("Battery", "Temp", "RAM") show the value at the pointer next to them; without a pointer they show the latest reading.

V4 · A readout bar above the charts

A fixed bar above the charts reads out the pointer’s time and all three values; it shows the latest reading when the pointer is elsewhere.

My recommendation

V1. It puts every value for one moment in one card, right where you are looking, and it has room for the context (pad state, the build or command under the pointer) that explains the numbers.
