Hardware page: each class with its models

A device now takes its class from its model, with no pick at enrollment, in the inbox, on the device page or in bulk (that part is built). So this page is where a class is decided: each class lists the models attached to it, and any device of one of those models, already enrolled or yet to come, is in that class. Our own hardware (T7, Kiosk 18/22/27) is built in to its class; any other model can be attached, moved or detached. A model can be attached before any device of it has enrolled. Data from the local stack.
