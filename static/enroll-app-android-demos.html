AIO Enroll for Android

The same app on a phone: sign in with your MDM account, see the devices on the same Wi-Fi, pair one with its code (or connect an AIO firmware device with no code, using the fleet key the app fetches after sign-in), pick the class and restaurant, enrol, and see it come online. Wi-Fi only. Each option shows the same five moments on a Pixel 6. Press ▶ Play to run a pairing and enrolment.
