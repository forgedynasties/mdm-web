AIO Enroll — one phone connected two ways

After Switch to Wi-Fi (or any time a phone is on the cable and on Wi-Fi) the same Pixel 6 shows up twice in the list: once for USB, once for Wi-Fi. They are one phone (same serial), so they should be one row. The app already knows this: both rows report the same serial number.

Each demo plays the story: USB only → press “Switch to Wi-Fi” → the Wi-Fi link joins the same row → unplug the cable. Press ▶ Play. What the app does behind the scenes is the same in all three: it keeps both connections, uses USB for actions while the cable is in (more reliable), and falls back to Wi-Fi when it's unplugged.

Option A
One row, two connection icons recommended
The row shows both icons side by side (cable + Wi-Fi). When the Wi-Fi link appears its icon pops in next to the USB one; when you unplug, the cable icon fades out and only Wi-Fi remains. The panel tells you what to do: “Connected by USB and Wi-Fi — you can unplug the cable.”

Good: simplest, immediately understandable, no new controls. Bad: per-connection actions (e.g. forget only the Wi-Fi link) need a place — the panel has a small “Connections” line for that.

Option B
One row, with a “Connected via” switch in the panel
Row shows both icons, and the panel has a segmented control [ USB | Wi-Fi ] showing which connection the app uses right now (USB by default while plugged in). Lets people deliberately test the Wi-Fi path without unplugging.

Good: full control, explains itself. Bad: an extra control most people never need.

Option C
One row with a “2” badge that expands into its connections
The row shows a small count badge. Click it and the row unfolds into one slim line per connection (USB, 10.32.2.210:5555) each with its own “Forget” (Wi-Fi only) — the same pattern as the Nearby phones group.

Good: every connection is visible and manageable. Bad: the most UI; overkill when nearly everyone has one or two.

Rules for all options

• Merge key: the phone's serial number. Different phones are never merged; a phone whose serial can't be read stays unmerged.
• Which connection acts: USB while plugged in (faster, doesn't drop), otherwise Wi-Fi. Enroll, reboot etc. go through that one.
• Forget only removes the Wi-Fi link (USB can't be forgotten from software). If both exist it forgets just Wi-Fi and says so.
• Saved phones list still remembers the Wi-Fi address, so after you unplug and later disconnect it can be reconnected in one click.
• The status mark (✓ / dot) and the model name are shown once, not twice.

Pick A, B or C.
