Enrollment pane on the device page

Today the card is one flat list that mixes three unrelated things: facts (how this device is managed, when it first appeared, which credential it holds), settings (its product class), and actions that change or end its life (move to another MDM server and reboot, retire, factory wipe) — all as identical rows, with the wipe button the same size and weight as everything else. Four re-cuts below, same data in each. Admin view; the card is admin-only.
