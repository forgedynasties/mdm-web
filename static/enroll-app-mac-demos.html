AIO Enroll — making it feel like a real Mac app

Today the app borrows the web dashboard's look (cards, orange outlines, big rounded pills, emoji-sized icons). A Mac app feels “professional” because it follows a small set of system conventions people already know from Finder, System Settings and Apple Configurator. Below: the same screen — Google Pixel 6, ready to enrol, connected by USB + Wi-Fi — redrawn three Mac-native ways. Each window has a light/dark switch and an interactive bit.

Window, not a web pageTraffic lights inside the window, a unified toolbar (title, search, account, “+”), and a translucent sidebar that blurs the desktop behind it (Tauri: titleBarStyle: Overlay + macOS vibrancy; Windows gets Mica).
System type and spacingThe system font (San Francisco) at 13 px, regular weight for text, semibold only for titles. 8-pt spacing, hairline (0.5 px) separators, tabular numbers for serials and versions.
Grouped lists, not cardsInformation sits in grey inset groups with label-left / value-right rows — the System Settings pattern — instead of coloured chips and boxes.
One accent, used rarelyAIO coral only for the selection and the one primary button. Status uses Apple's green/amber/red as small pills, never full-colour panels.
Native controlsSegmented control for the class, real switches, push buttons with a hairline border; “Forget” and “Switch to Wi-Fi” become plain buttons in a row, destructive in red text.
Sheets, menus, shortcutsThe pairing code drops down as a sheet from the toolbar (not a centred web modal); a real app menu (File ▸ Add over Wi-Fi ⌘N, View ▸ Only ours ⌘⇧O); right-click menus on rows; ⌘R refresh, ⌘↩ enrol.
Option A
System Settings style: sidebar + grouped detail recommended
Sidebar sections Devices · Nearby · Saved with small coloured glyphs (like Settings), a unified toolbar, and the device shown as grouped rows: Device, Connection, Enrollment. The class is a segmented control; Enrol is the only coloured button. Press Pair a phone… in the sidebar to see the sheet.
Appearance

Good: instantly familiar to every Mac user, scales to many devices, calm. Bad: the biggest visual change from today (logic and features stay identical).

Option B
Apple Configurator style: device tiles + inspector
Connected devices as large tiles with a drawing of the hardware (phone, TV box, KDS), status as a small badge on the tile. Select a tile and the details appear in the same grouped rows underneath. Feels great on a bench with several devices plugged in.
Appearance

Good: very visual, obviously “a device tool”. Bad: needs simple drawings per hardware type; less room for long lists.

Option C
Today's layout, Mac-polished
Keeps the current structure (rail + centred panel) but swaps the web styling for Mac details: vibrancy sidebar, system font, hairlines, segmented class picker, smaller icons, native buttons. Least change.
Appearance

Good: lowest risk, quick. Bad: the centred big-icon panel still reads a little “web”.

All animations
Every motion in the app, Mac style
Short, springy, and only where something actually changed — the way macOS moves. Press ▶ Play all, or play one at a time. Durations are 0.2–0.45 s with an ease-out spring; everything turns off with the system's “Reduce motion”.

What moves, and why: rows slide in when a device appears · the selection glides between rows · the detail pane cross-fades · the segmented thumb slides · Enrol turns into a progress bar with steps ticking off · success springs in and the sidebar row gets its green badge · a Notification Center banner when done · the pairing sheet drops from the toolbar and shakes on a wrong code (like a wrong Mac password) · unplugging fades the cable icon out · a blocked phone pulses red once · switches slide.

What changes in the app, whichever you pick

• Window: overlay title bar with the traffic lights in our toolbar, macOS vibrancy on the sidebar, Mica on Windows, normal title bar on Linux.
• Typography and icons: system font stack, one consistent 1.6-stroke icon set at 13–16 px (no emoji anywhere), tabular numbers.
• Native menus and shortcuts: app menu, right-click menus on devices, keyboard shortcuts listed in the menus.
• Sheets for the pairing code and sign-in instead of centred pop-ups; notifications (Notification Center) when an enrolment finishes while the window is in the background.
• Dark mode follows the system exactly, with Apple's dark greys instead of our near-black.
• Everything the app does today stays: pairing, merge, nearby/ours, enrolled by, adb help.
