Compliance rules

How an admin says what "compliant" means. The model from the plan: one fleet baseline (each check required, recommended or off, plus auto-fix where a fix exists), then overrides for a venue, group or role, first match wins, like lock rules. Each option shows the same setup. In it, the lab and no-venue devices only get recommendations, and auto-fix is on just for wireless adb and client updates.

Every check is visible in one place, in plain words, with how many devices can answer it. It shows what each one means before you save ("3 devices would change"). Overrides read as sentences.

Recommendation

B1 to edit, with B3 as a read-only "What applies where" view under the overrides for auditing. B2 is tempting for consistency with lock rules, but compliance has per-check settings (thresholds, auto-fix) that a three-question card can't hold.
