Where the admin pages live

The dock is the same for everyone now — Overview, Fleet, Actions, Alerts. The question is where Policies, Updates, Users, Products and Clients go, since only some roles have them. Five options below. Each mock shows what an admin sees; a viewer sees the same dock and none of the extras.

Option 1on stage now
Right rail

A second floating pill against the right edge.

Against: two floating things competing, it sits over wide tables, and it has no obvious relationship to the dock.

Option 2my pick
One “More” in the dock

The dock keeps its four, plus a fifth that opens the admin pages above it.

For: one navigation object, not two. The dock is still identical for everyone — a viewer simply has no More. Nothing floats over the content.

Option 3
In the account menu

Admin pages become a section of the existing top-right menu, under the avatar.

For: nothing new is added to the screen at all — that menu already holds Settings and Sign out. Against: Clients and Updates are daily work for an operator, and this buries them a click deep behind a menu people open rarely.

Option 4
Secondary bar, only on those pages

A thin tab strip under the header, shown only while you are in an admin page.

For: zero footprint everywhere else, and once you are in that area, moving between its pages is one click. Against: you need another way in the first time — it pairs with Option 2 or 5 rather than replacing them.

Option 5
An “Admin” hub page

One dock entry leads to a page that lists the admin areas as cards.

For: the dock stays four-plus-one, and the hub has room to say what each page is for — useful while Clients and Products are new. Against: every admin page is now two clicks away. Best combined with Option 4.
