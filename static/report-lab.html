Hourly Report — design options

Same data, five treatments. No emojis, no pill chips — severity shown by colour, dots, or stripes. Pick one (or mix-and-match: e.g. metrics from one, issue list from another).

Option 1 — Editorial
Thin coloured left-rule per issue. Reads like a written brief; calm and text-forward.
