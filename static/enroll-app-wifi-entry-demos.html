AIO Enroll · adding a phone over Wi-Fi

The “Add over Wi-Fi…” button and the page it opens go away. The app is always listening for phones: plug one in, or open Pair device with pairing code on it, and it turns up on the left by itself. A pairing screen pops the code sheet straight away. The main page only has to say how to get the phone to that point. Press ▶ Play on any option to watch a phone pair from start to finish.
