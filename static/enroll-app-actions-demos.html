AIO Enroll — the actions area of the device panel

The icon row we just built has three problems (visible in your screenshot): 1) the hover tooltip is big and covers the buttons next to it (here, “How to fix”); 2) a lone ✕ in an orange box doesn't say what it removes — it looks like a delete button; 3) the “OK to unplug” chip floats loose beside it, so it isn't clear what it belongs to.

Three calmer ways to group the same actions. Switch situation to compare; the first column is today.

Today

Option B · “⋯” menu

Option C · connections card

Option A
A footer strip with words, not mystery icons recommended
A thin divider, then small quiet text buttons that say what they do — Forget Wi-Fi link, Switch to Wi-Fi, Forget device — and a plain green line “✓ OK to unplug the cable” when it is on both. No tooltips needed, nothing overlaps, and nothing looks like a primary action. Destructive ones turn red only on hover.

Good: self-explanatory, tiny, one tidy place. Bad: uses a little more width than icons.

Option B
One “⋯” button that opens a menu
A single small button in the corner of the panel opens a labelled menu (with a one-line description under each item). Zero clutter in the panel itself; everything occasional lives in the menu.

Good: cleanest panel, room for more actions later. Bad: one extra click, and “OK to unplug” has to become a chip somewhere else.

Option C
A small “Connections” card, one line per connection
A tiny card lists how the phone is connected — USB cable ✓ · in and Wi-Fi 10.32.2.210:5555 [Forget] — each action sits on the line it affects, so it is obvious what “Forget” removes. A phone on cable only gets one line plus a “Switch to Wi-Fi” link.

Good: most explicit, impossible to misread. Bad: the most visible UI for something used rarely.

Also (any option)

• Tooltips stay for the few icons left, but small, placed below the control and never over a neighbouring button.
• “How to fix” stays where it is, with the actions area clearly separated below it.
• Success/failure messages show in the same strip, replacing the buttons for a few seconds.

Pick A, B or C.
