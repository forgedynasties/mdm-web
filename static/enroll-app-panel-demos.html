AIO Enroll — less text in the device panel

Today the panel stacks sentences: “Has an account — factory reset, don't add an account. Then plug it in again.”, then “Connected by USB and Wi-Fi — you can unplug the cable.”, then a connections line, then notes under each button. It reads like a manual. The idea in all three options: say the state in a word, show the action as a button or icon, and put the explanation one click away — only when someone wants it.

Use the switch to compare the same situation in every design. The first column is what the app shows today.

Option A
Status chips, one short line, “?” opens the how-to recommended
Facts become small chips (Android 17 · USB + Wi-Fi · Has account). The problem is one short line (“Has an account”) with a “How to fix ?” button that opens a small popover with the steps. Secondary actions turn into icon buttons with hover tooltips (switch to Wi-Fi, forget).

Good: the panel is almost text-free; everything is still reachable. Bad: icon-only buttons need a hover to learn (tooltips and a consistent set of icons fix that).

Option B
Same short headline, long explanations in a “Details” fold
Keeps normal text buttons (clearer than icons), but every explanatory sentence moves behind a Details › fold that stays closed. The app remembers if you open it.

Good: simplest, no icon learning. Bad: a first-timer might not open the fold — fine for “blocked”, where the one-liner already says what is wrong.

Option C
A small info card: icon rows instead of sentences
Each fact is a row with an icon, a label and a value (Connection · USB + Wi-Fi ✓, Account · has one ✗ “Fix”, MDM · registered ✓). One primary button below. No paragraphs at all.

Good: very scannable and uniform for every device type. Bad: most structural change; a bit “dashboard-y” for a setup tool.

Wording diet (all options)

• “Has an account — factory reset, don't add an account. Then plug it in again.” → “Has an account” (steps in the popover/fold).
• “Connected by USB and Wi-Fi — you can unplug the cable.” → “USB + Wi-Fi ✓” chip and a small “OK to unplug”.
• “No pairing and no codes. Reads the phone's IP over the cable…” → button “Switch to Wi-Fi”, explanation only in a tooltip.
• “Only disconnects it from this computer. It stays enrolled in the MDM.” → tooltip on Forget.
• “Already runs AIO MDM firmware” + “Registered in the MDM as t7. Nothing to do here.” → “AIO firmware ✓ Registered”.
• Everything keeps working in the same places; only the amount of text changes.

Pick A, B or C.
