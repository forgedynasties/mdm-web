"Enrolled by" on the dashboard

AIO Enroll records which account enrolled each device (devices.enrolled_by, a username, with the app's own name on the enrollment profile). The app shows it; the dashboard doesn't, anywhere. Three places it could go — pick any mix. The sample data is live: the five Tonight Rollout devices were backfilled to Ali; the Pixel 3a XL was moved from stage by hand, so it has no enroller, which must read as "not recorded", not as a blank.
